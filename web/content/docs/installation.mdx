---

autocurl is distributed as a single static binary with zero external runtime dependencies. It utilizes the native `curl` binary already present on your system.

## 1. macOS & Linux via Homebrew (Recommended)

The simplest way to install and keep autocurl up to date is via Homebrew:

```bash
brew install autocurl
```

To update autocurl in the future, simply run:

```bash
brew upgrade autocurl
```

## 2. Quick Shell Installer

If you do not use Homebrew or are working inside a CI/CD runner or remote Linux container, install via curl:

```bash
curl -fsSL https://raw.githubusercontent.com/anshuman/autocurl/main/install.sh | bash
```

## 3. Manual Binary Download

Precompiled standalone binaries are available on GitHub Releases for every major architecture:

| Operating System | Architecture |
|---|---|
| **macOS** | Apple Silicon (M1/M2/M3) & Intel x86_64 |
| **Linux** | x86_64 & ARM64 (aarch64) |
| **Windows** | x86_64 executable (.exe) |

## Verifying Installation

Verify that autocurl is accessible in your current shell path:

```bash
$ autocurl --version
autocurl 0.1.0 (x86_64-apple-darwin)
```

## System Requirements

autocurl relies on the standard `curl` binary installed on your machine. Ensure that `curl` is available in your PATH (which is default on macOS, modern Linux, and Windows 10/11).
