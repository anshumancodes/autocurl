Detailed synopsis, command-line arguments, flags, and exit codes for the `autocurl` binary.

## Synopsis

```bash
autocurl [file] [options]
```

## Flags & Options

| Flag | Type | Description |
|---|---|---|
| `[file]` | String | Path to definition (`.js`) or compiled (`.acr`) file. Defaults to `index.js` or `index.acr` if omitted. |
| `-r, --run <name>` | String | Execute a request by its name immediately without opening the interactive terminal picker. |
| `-d, --dry-run` | Boolean | Print the fully formatted curl command to stdout instead of sending network packets. |
| `-g, --generate` | Boolean | Compile the input JavaScript file to .acr and exit immediately. |
| `--filter <query>` | String | Launch the terminal picker pre-filtered with the matching search query. |
| `-v, --verbose` | Boolean | Instruct cURL to print verbose request and response header diagnostics (`curl -v`). |
| `-V, --version` | Boolean | Display installed autocurl version and system architecture. |
| `-h, --help` | Boolean | Display help information and command syntax. |

## Exit Codes

autocurl follows standard UNIX exit code conventions for clean integration in bash scripts and CI runners:

- **0 (SUCCESS)** — The command or HTTP request completed without error.
- **1 (ERROR)** — cURL execution failed or returned a non-2xx status code.
- **2 (PARSE_ERROR)** — The input file could not be read or contains invalid syntax.
