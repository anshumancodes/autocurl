autocurl is a local-first, developer-friendly command-line tool that simplifies generating, organizing, and executing curl requests. Define your API calls in JavaScript, generate plain `.acr` files, and run them with an interactive terminal selector.

## Core Architecture: Separation of Concerns

Traditional API tools either force you into heavy GUI applications with proprietary cloud databases, or leave you wrestling with unwieldy, unquoted bash strings. autocurl separates the request lifecycle into three distinct, transparent phases:

### Phase 1: Definition (index.js)
Structured JavaScript array containing endpoint URLs, HTTP methods, headers, and request bodies. Fully programmable and clean.

### Phase 2: Representation (index.acr)
Clean, human-readable curl commands separated by readable headers. Tracked in git, diffable in pull requests, zero lock-in.

### Phase 3: Execution (Terminal Runner)
Interactive keyboard-driven selector or direct command runner that delegates directly to native cURL on your machine.

## Why Developers Use autocurl

Developers reach for curl because it is universally available, fast, and has no moving parts. However, managing 20+ curl commands in Markdown files, scratchpads, or shell histories is painful. Flags are forgotten, quotes are corrupted, and tokens are accidentally overwritten.

GUI clients like Postman or Insomnia solve organization, but at the expense of hundreds of megabytes of RAM, forced account logins, cloud storage of private endpoints, and opaque JSON export files that break git merges.

**autocurl** gives you the best of both worlds: structured request authoring in JavaScript, plain-text curl storage on your disk, and an instant terminal runner.
