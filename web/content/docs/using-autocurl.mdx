## AI-assisted discovery with your own Gemini key

The default `--ai=off` mode performs deterministic local discovery and makes no network requests. It needs no API key. Optional AI analysis runs in the Go CLI and connects directly to Google's Gemini API; no autocurl backend or account is required.

### Get a Gemini API key

Create a key in [Google AI Studio](https://aistudio.google.com/app/apikey), then set it in your shell. Do not paste it into source code or `.autocurl` files, and do not commit it.

```bash
export GEMINI_API_KEY="your_api_key"
```

For a one-command setup, set the variable in the same shell before running autocurl. Avoid putting the key in project configuration files. The CLI reads it at runtime and sends it only to Google's Gemini API over HTTPS. It does not print or write the key. The bounded, redacted source context for AI analysis is sent to Google; inspect your provider's privacy and retention terms before enabling AI. You are responsible for Gemini usage and any provider charges.

| Flag | Behaviour |
|---|---|
| `--ai=off` | Local deterministic discovery only; default and offline. |
| `--ai=auto` | Uses Gemini only if AST discovery finds unresolved or unsupported routes or no routes. The key is needed only if that analysis is invoked. |
| `--ai=always` | Requests Gemini analysis for every generation. Requires `GEMINI_API_KEY`. |

CLI flags override `AUTOCURL_AI`. Without an API key, `auto` still succeeds when AI is not needed. When AI is needed, missing or rejected credentials are reported clearly. Rate limits, network errors, and timeouts are reported without exposing the key. When provider service failures occur, deterministic AST routes remain available.

### Troubleshooting

- **Missing key:** export `GEMINI_API_KEY` in the same shell, or use `--ai=off`.
- **Key rejected:** verify the key in Google AI Studio, ensure Gemini API access is enabled, and remove accidental surrounding whitespace.
- **Rate limited:** wait and retry; usage and limits are controlled by Google for your account.
- **Timeout/network failure:** check connectivity and retry. AI calls have a bounded timeout; local discovery remains available with `--ai=off`.
- **No AI route accepted:** AI suggestions are validated against source evidence and may be discarded if ungrounded or unsafe.

## Scope generation

Run autocurl with a project root, a module/directory, or a supported source file:

```bash
autocurl ./my-api                 # project-wide generation
autocurl ./my-api/src/modules/users # directory-scoped generation
autocurl ./my-api/src/routes/users.js # file-scoped generation
```

Route extraction is implemented for Express and NestJS (JavaScript/TypeScript), FastAPI, Flask, and Django (Python), and Gin, Echo, Fiber, and `net/http` (Go). Framework detection is a separate identification step: detecting a framework does not mean its routes can be extracted. Extractors retain project context for mounted routes and framework relationships. The output includes only routes in the selected scope, with source locations. Existing `.autocurl` output is protected from overwrite; rename or remove it before regenerating.

## CLI options

```bash
autocurl [--ai=off|auto|always] <project-directory|source-file>
autocurl <file.autocurl>
autocurl --version
```

AI mode defaults to `off`. `--ai` applies to generation; executing an existing `.autocurl` file remains local to the CLI.

## `.autocurl` format and execution

Generated files are plain text and remain suitable for review and version control. They contain a base URL, request separators, source annotations, method and URL, headers, and an optional body. AI credentials are never included.

```http
# Generated by autocurl
# Project: express-api

@baseUrl = http://localhost:3000

### 1. GET /health
# @source server.js:4
GET {{baseUrl}}/health
Accept: application/json
```

Run a file to select and execute a request interactively:

```bash
autocurl index.autocurl
```

autocurl resolves `{{variable}}` placeholders interactively, executes requests with its built-in Go HTTP client, and formats JSON responses. The parser and executor work independently of Gemini configuration.
